# JARVIS

A local-first AI desktop assistant for Windows.

## Vision

JARVIS is designed to act as a personal AI desktop agent capable of understanding natural-language voice commands and interacting with Windows applications, files, and websites.

## Core Goals

- Voice-activated interaction
- Speaker verification
- Local speech recognition
- Local AI reasoning
- Tool-based computer control
- Browser automation
- Windows application automation
- Text-to-speech responses
- Persistent user memory
- Safety and confirmation controls
- Windows startup support

## Development Status

🚧 Early development — Phase 1

## Technology

- Python 3.11
- Local AI models
- Windows automation
- Browser automation
- PySide6
- SQLite
